## 🎯 Key Findings

### OE — OCCUPATIONAL EMPLOYMENT (25 chars)
```
OEUN000000000000015121101
├─ OE (survey) + U (unadjusted)
├─ N (national) + 0000000 (national area)
├─ 000000 (cross-industry) + 151211 (SOC: Software Developers)
└─ 01 (total employment)
```

**15 datatype codes** (employment, wages, percentiles, RSE)  
**Always unadjusted** (no seasonal adjustment)

### CE — CURRENT EMPLOYMENT (20 chars)
```
CES0000000001
├─ CE (survey) + S (seasonally adjusted)
├─ 00000 (US national) + 000000 (state-level)
├─ 00 (total nonfarm) + 00 (total industry)
└─ 01 (all employees in thousands)
```

**10 datatype codes** (employment, hours, earnings)  
**Both SA and NSA** versions available

### LN — LABOR FORCE (12 chars)
```
LNU02000000
├─ LN (survey) + U (not seasonally adjusted)
├─ 020 (unemployment rate series)
├─ 0000 (all persons, 16+)
└─ 00 (reserved)
```

**6 main series codes** (labor force, unemployment, employment, etc.)  
**14 demographic codes** (age, sex, race, education)  
**Both SA and NSA** versions available

## ⚠️ Known Limitations & Gotchas

1. **OEWS is annual, not monthly**
   - Data released May (for prior May reference month)
   - Never seasonally adjusted
   - Use code 'U' always

2. **CES and CPS are monthly**
   - Released early each month
   - Both SA and NSA versions available
   - Codes 'S' or 'U' required

3. **Some combinations suppressed**
   - Not all occupation-industry-area combinations exist
   - API returns `"no observations"` if data doesn't exist
   - Plan for graceful error handling in UI

4. **Metadata file downloads are rate-limited**
   - Direct HTTP downloads may be blocked by BLS robots.txt
   - Use BLS API for lookups instead
   - Cache results locally (6-month validity reasonable)

5. **FIPS codes for CE**
   - 5-digit state codes: `00000` (US), `01000` (AL), `02000` (AK), etc.
   - Full list: https://www.census.gov/geographies/reference-files/2020/codes/fips-codes.html
